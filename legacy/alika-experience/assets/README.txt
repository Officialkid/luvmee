PROJECT ALIKAH — ASSETS DIRECTORY
==================================

This folder contains local media assets for Project ALIKAH.

1. BACKGROUND MUSIC (Optional):
   - Place an MP3 file named "music.mp3" directly in this folder (`assets/music.mp3`).
   - Project ALIKAH will automatically detect and play it when Alikah taps the "Music" button.
   - If no MP3 is provided, Project ALIKAH includes an integrated Web Audio romantic lofi synthesizer that plays soft ambient electric piano chimes out-of-the-box, so music never breaks!

2. CUSTOM PHOTOS OR ICONS:
   - You can place your personal photos with Alikah here (e.g., `assets/photo1.jpg`).
   - To show a photo in Scene F (The Personal Note) or Scene G (The Final Surprise), simply add:
     `<img src="assets/photo1.jpg" alt="Alikah and me" class="custom-photo">`
     inside the respective card in `index.html`.
